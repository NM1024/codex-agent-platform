# v1.0.8

- 升级支持官方预构建镜像和源码构建，默认使用官方镜像；网页与命令行共用相同备份、数据保留和健康检查流程。
- 官方 Linux amd64 镜像由 CI 构建验证，发布时复用通过检查的镜像；GHCR 不可用时使用公开 Release 镜像包。下载或校验失败在停服前结束，不会暗中改为源码编译。
- 优化 Docker 依赖层，应用版本号变化不再单独使依赖安装层失效，并去除镜像内 npm 下载缓存。
- 增加项目镜像清理预览及显式执行命令，保留最新三个版本和所有容器引用；不清理其他应用、数据卷或私密备份。

旧版部署可以下载本 Release 的 update.sh，执行 `sudo bash /tmp/codex-platform-update.sh update --method image`，或将 image 改成 source。多个实例在 update 后追加原运行目录。新镜像目前只覆盖 Linux amd64，其他架构请选择源码构建。
