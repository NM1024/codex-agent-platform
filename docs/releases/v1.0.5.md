Codex Agent Platform v1.0.5。

- 新增「系统运维」页面，包含待处理问题、后台工作和系统日志；支持搜索、筛选、分页、来源状态、关联日志与工作详情。
- 覆盖清理、配置同步、内部事件回传、运行核对、定时计划与巡检交接、历史清理、通知/回调和服务健康等主要内部链路。工作状态、问题恢复和核验情况分别显示；来源失联时保留并标记过期证据。
- 统一使用「交给管理 Agent」进入对话：先查证据，在已有权限内处理并核验；不能解决就说明原因、影响和未解决事项，不主动追加 issue 或草稿流程。只有用户明确需要时才提供脱敏草稿，且不提交 GitHub。
- 日志、诊断和草稿不控制系统运行；旧候选缺陷标记不再阻断后台工作或受控维护。日志存储失联时，Runner 仍可通过所属运行记录发现待清理目录；日志清理失败不会丢失已经完成的独立历史清理进度。
- 系统日志遵循现有历史清理开关与保留天数，保护未完成、未恢复的必要证据；完成并恢复的记录不因诊断标签额外延长保留时间。
- 完善对话删除后的清理反馈，修复旧「升级完成」提示反复出现；有明确单位的输入框在右侧固定显示单位。
- 保持现有界面风格，完善详情对齐、中英文和手机布局；为接入弹窗的保存按钮提供稳定的无障碍名称，避免加载图标影响识别。运维筛选的小型选项列表关闭虚拟滚动，提升滚动与选项定位稳定性。

现有安装可打开版本弹窗升级，或在实际部署服务器执行：

```bash
curl -fL https://github.com/NM1024/codex-agent-platform/releases/latest/download/update.sh -o /tmp/codex-platform-update.sh
sudo bash /tmp/codex-platform-update.sh update
```

多个实例请在 `update` 后加上已有运行目录。更新会备份运行数据、构建镜像并重启服务，保留现有配置、账户授权和历史；完成后刷新浏览器。平台与可选沙箱镜像版本统一为 `1.0.5`。已发布的旧标签与发行文件保持不变。
