Codex Agent Platform v1.0.6。

- 修复升级只构建沙箱镜像、没有安装启动辅助服务的问题。在支持的 root 管理 Linux/systemd 环境中，正常启动与正式版升级会自动安装启用沙箱；已经启用的辅助服务随版本更新，用户明确关闭过的设置保留。
- 沙箱自动更新保留已有的上游代理策略；内容未变化且正常运行时不重启辅助服务。安装锁被占用或宿主环境不支持时给出提示，主服务升级继续进行。沙箱策略文件纳入后续升级备份。
- 侧边栏七个页面使用独立地址，支持刷新、直接打开链接和浏览器前进后退；未登录时先登录，再进入对应页面。保持现有页面布局和样式，旧 `/admin/` 入口继续可用。
- 删除任务记录筛选栏上方的结果说明文字。

现有安装可在版本弹窗检查更新并升级到 v1.0.6。旧版更新程序通过新版部署验证步骤自动完成沙箱安装，无需另行执行沙箱启用命令。用户明确关闭过沙箱、或不支持所需宿主环境的安装除外。

更新会备份运行数据、构建镜像并重启服务，保留现有配置、账户授权和历史。辅助服务更新会结束沙箱当前代码运行并移除临时工作区；已经发布到对话的附件保留。更新完成后刷新浏览器。
