Codex Agent Platform 首个正式版本。

- 业务插件支持指定模型和思考程度，已接单任务保留其配置快照。
- 旧管理对话每轮获取当前平台规则；管理 Agent 可只读查看部署中的管理代码、前端和文档。
- 历史清理默认关闭，可设置 30/60 天或自定义期限，永久删除到期对话、已结束任务及关联图片和文件。
- 管理并发默认 2，可配置 1–5；SQLite 排队、分页恢复、SQL 缓存、SSE 背压和图片处理控制内存峰值。保留 Codex 原有上下文压缩策略。
- 新增稳定版本自动更新：自动识别标准 Git/源码包 Compose 安装，只获取最新正式 Release，校验 SHA-256，构建、停服备份、重启并检查健康状态。保留原配置、授权和历史。
- 修复 CI 中响应式代码块测量的偶发时序问题；从最终发布包构建并验证镜像。

首次更新现有安装：

```bash
curl -fL https://github.com/NM1024/codex-agent-platform/releases/latest/download/update.sh -o /tmp/codex-platform-update.sh
sudo bash /tmp/codex-platform-update.sh update
```

成功后按脚本输出的路径执行，例如：

```bash
sudo bash /data/codex-agent-platform/deploy.sh update
```

要求 Linux、Python 3.10+、curl、Docker Engine、Docker Compose v2 2.20+。多个实例需在 update 后指定原运行目录；自定义 Compose 覆盖文件需手动升级。更新构建需要访问 GitHub、npm 和镜像仓库。备份期间会停服，时长取决于数据量；备份包含密钥与账户授权，需私密保管并预留磁盘空间。健康失败不会自动降级已迁移数据库，恢复步骤见 docs/DEPLOYMENT.md。自动清理不删除独立备份。

本次发布不在生产服务器上执行升级，也不提交真实模型任务。健康检查确认服务存活，不代表账户或模型额度可用。
