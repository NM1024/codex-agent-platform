Codex Agent Platform v1.0.4。

- 管理对话的发送与停止共用一个图标按钮。执行中可停止当前轮次，保留已输出回复；人工停止不会在重启后自动续跑，并等待沙箱清理完成后再启动后续排队消息。
- 任务记录增加「插件任务 / 定时任务」两个 Tab；定时执行记录使用统一 Table，支持搜索、状态筛选、分页和详情，包含已删除计划的执行历史。
- 两类执行记录的调查入口均增加二次确认，确认后才创建 Agent 调查对话。
- Cron 改为可直接输入的独立弹出选择器，支持频率、时间和日期交互；时区可搜索，并预览接下来三次执行。补齐键盘操作与手机、横屏布局。
- 定时执行详情使用只读组件展示通知渠道和通知结果，不再出现绑定输入、保存按钮。通知绑定编辑统一表单和底部保存，移除正常状态下常驻的「重新读取」。
- 定时计划与修改后的通知绑定进行原子版本校验；未修改绑定时保留独立绑定版本，未修改执行时序时保留下次触发时间。

现有安装可在实际安装目录执行：

```bash
sudo bash /opt/codex-agent-platform/deploy.sh update
```

更新会构建镜像、备份并重启服务，保留现有配置和历史。更新完成后刷新 Admin 页面以载入新界面。平台与可选沙箱镜像版本统一为 `1.0.4`。

已发布的旧 tag 和发行文件保持不变。
