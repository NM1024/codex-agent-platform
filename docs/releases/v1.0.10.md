# v1.0.10

- 快速模式关闭时显示空心闪电，开启时显示实心闪电；输入框下方按“模型名称 - 思考程度 - 快速模式图标”展示，普通模式不显示快速模式图标。继承全局设置和显式普通模式覆盖使用同一有效状态。
- 系统运维的待处理问题、后台工作和系统日志统一将服务放在第一列，以 Tag 显示 Manager、Gateway、Runner，编号单独成列。手机端保留服务优先及名称、状态的既有卡片布局。
- 后台工作隐藏与当前状态重复的成功说明和零问题次数，保留真实异常原因、错误码、历史问题次数及详情诊断。运行版本、版本检查、系统升级等工作使用简明名称；系统日志保留事件结果信息。
- 运维说明统一移到各表格标题旁，去掉单独占行的说明框；手机端在标题区域内自然换行。
- 插件任务和定时执行记录使用与运维一致的表格卡片、查询区和刷新入口。新增业务类型、计划类型及时间范围筛选，支持组合查询、重置筛选和键盘提交。已删除插件的历史类型仍可手动输入查询。
- 筛选后回到第一页，分页和刷新保持同一查询时间范围，总条数由同一筛选条件统计；每页仍可选择 10、20、50、100 条。
- 验证改为开发环境执行代码检查和受影响的页面回归。PR、普通推送和每周定时不再自动运行 GitHub 测试；GitHub 仅在手动发布时构建官方镜像、打包并校验公开下载文件，发布前核对已在本地验证的完整提交编号与正式版本。
