Codex Agent Platform v1.0.7。

- 修复网页升级辅助服务启用只读系统目录保护时，沙箱自动安装失败的问题。新版通过固定的受信安装步骤完成安装，保留升级服务原有保护；用户明确关闭过沙箱的设置继续保留。
- 沙箱增加每分钟只读健康检查，恢复后及时重试既有清理队列；检查不重建工作区、不重放命令。单项清理仍失败时继续保留记录并按退避重试，不影响正常业务。
- 系统运维统计改为紧凑的可点击筛选项，分别定位未恢复问题、等待重试、运行中及过去 24 小时恢复的记录。恢复时间按实际恢复时刻筛选。
- 运维页面宽度与其他列表页面统一；已完成、空闲、未启用的记录不再显示无进展时长。网页升级辅助服务状态改为实际探测结果。

从 v1.0.6 网页升级到此版本，会自动重试未完成的沙箱安装；无需为了本次安装遗漏另行执行启用命令。安装仍需支持 Linux、systemd、Docker 以及受信的 root 所有目录。已明确关闭的沙箱不会自动打开。
