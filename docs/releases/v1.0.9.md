# v1.0.9

- 修复旧版管理巡检已经在原对话完成，但定时执行历史仍显示“排队中”的兼容问题。管理服务通过巡检、原对话和原始消息的关联补齐完成或失败状态，关闭计划不会改变历史执行结果。
- 旧记录无法确认原对话或原消息时，保留待核验问题，不新建替代对话或重新生成结果。已结束的原消息不会自动重跑，通知也不会因为历史状态修复而重发。
- 修复领取请求被拒绝仍记录交接成功、交接检查仍显示正常的问题。持续未确认的交接显示待核验及待处理数量；并发取消造成的过期列表不误报。
- 领取日志只记录实际状态变化，重复轮询不再累计为成功领取次数。系统日志继续遵循现有历史保留和清理策略。
- 历史清理只处理已确认完成、失败或取消的巡检。启动时清除旧版为未结束记录误填的结束时间；即使残留旧时间，清理时仍核对终态，保留待核验记录及其执行历史。
- 修复管理轮次在模型校验期间超时、停止或断线后仍可能发起执行的问题；浏览器保存对话模型设置增加并发校验，避免覆盖其他页面或管理 Agent 的修改。上游错误保留脱敏的诊断类别和安全说明。
- 对话标题与连接状态合并到顶部，精简模型设置面板，快速模式使用闪电按钮；保存失败改为可重试的浮动提示，保留原对话的草稿和附件。
- 图片与文件统一使用一个附件入口，选择、拖拽和粘贴按文件类型分流，支持混合附件及连续操作。草稿附件单行展示，图片隐藏名称，删除按钮放在右上角。
- 任务记录、定时执行记录和系统运维统一分页样式，每页可选 10、20、50、100 条，并显示筛选后的总条数。调整筛选或每页条数时回到首页；读取失败或来源不完整时不会把旧数据冒充准确总数。
- 删除概览、运维和配置顶部的冗余说明及重复来源状态；保留实际故障、过期证据和采集缺口提示。手机布局与桌面保持一致。

升级后管理服务会在正常巡检交接检查中核对旧记录；原对话和原消息均保留时，可自动修正历史状态。若原始历史已被删除，则无法据此断言任务已完成，应通过管理 Agent 核对现存证据，不应直接重试业务任务。
