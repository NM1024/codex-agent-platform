Codex Agent Platform v1.0.3。

- 新增通用通知渠道，支持飞书/Lark、企业微信、钉钉、Slack、Discord 和自定义 Webhook。同类渠道可配置多个实例；业务插件和定时计划可绑定具体通道，由 Agent 按任务要求组织消息并决定何时发送。已结束执行仅展示通知结果。
- 模型配置新增普通/快速模式，默认普通模式，并提供回复详细程度、公开思考摘要、自动压缩阈值和工具输出预算四项高级控制。对话页面只保留模型、思考程度和速度选择。
- 管理 Agent 可在对话独立的隔离容器中使用 Python、Node.js、文件读写、命令执行和测试，支持文件上传与产物下载。联网等特殊操作按具体请求向用户申请授权，管理权限仍通过管理 MCP 执行。
- 文件按类型预览；文本和代码使用侧边抽屉，Markdown 支持解析与原文切换。授权交互归属发起请求的 Agent 气泡。
- 管理页面统一紧凑表单、弹窗编辑、抽屉详情和动态渠道选择，补齐手机端分类导航及窄屏布局。编辑冲突保留草稿，关闭弹出层后迟到的响应不会重新打开它。

现有安装可在实际安装目录执行更新，例如：

```bash
sudo bash /opt/codex-agent-platform/deploy.sh update
```

更新会构建镜像、备份并重启服务，保留现有配置和历史。使用代码沙箱前，请按 [沙箱部署说明](https://github.com/NM1024/codex-agent-platform/blob/v1.0.3/docs/SANDBOX.md) 安装或更新宿主机沙箱服务；更新沙箱服务会停止当前沙箱任务，已交付附件继续保留。沙箱镜像及平台镜像版本统一为 `1.0.3`。

已发布的旧 tag 和发行文件保持不变。
