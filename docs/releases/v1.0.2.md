Codex Agent Platform v1.0.2 正式版。

- 网页升级服务改为标准 Linux/systemd 部署默认配置，首次启动自动安装，旧版升级自动补装，无需再额外执行安装命令。
- 已运行的更新服务不会在自己的升级过程中被重启。
- `disable-web-update` 的关闭选择会持久保存，后续启动和更新不会自动开启；兼容旧版已禁用的服务，`enable-web-update` 可恢复配置。
- 不支持 systemd、非 root 或路径权限不符合要求时，脚本会说明原因，命令行更新和业务部署仍可使用。
- 网页提示、安装文档及备份范围同步更新；宿主机权限仍限于既有更新服务，不向管理 Agent 开放任意命令。

现有安装执行原来的更新命令即可：

```bash
sudo bash /data/codex-agent-platform/deploy.sh update
```

请使用实际运行目录。更新会构建镜像、停服备份并重启，保留配置、授权和历史。完成后刷新网页即可查看版本与升级状态。标准 root/systemd 环境自动补装；若脚本提示网页服务配置失败，可先查看：

```bash
sudo bash /data/codex-agent-platform/deploy.sh web-update-status
```

如需关闭：

```bash
sudo bash /data/codex-agent-platform/deploy.sh disable-web-update
```

首次安装示例使用 root 在 `/opt` 下创建源码目录，以满足更新服务的可信路径要求。更多环境要求、重试配置和故障恢复见 [部署文档](https://github.com/NM1024/codex-agent-platform/blob/v1.0.2/docs/DEPLOYMENT.md#host-service-for-browser-upgrades)。已发布的 v1.0.0/v1.0.1 文件保持不变。
