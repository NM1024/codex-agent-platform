Codex Agent Platform v1.0.1 正式版。

- 业务插件的“模型设置”移入“配置接入”的第三个页签，入口、回调和模型各自保存，切换页签保留未保存内容。
- 插件列表操作改为图标，保留中英文悬停提示和无障碍名称。
- Admin 顶栏显示运行中的实际版本，可检查最新正式版、查看发布说明和复制升级命令。
- 新增可选的 Linux/systemd 宿主机更新服务；安装后可在网页确认升级、查看进度，并在重启后恢复状态。升级只选择已发布的稳定 Release。
- 更新完成后核对运行镜像、健康状态和容器内版本；管理 Agent 不开放升级、任意 Shell 或 Docker 权限。

从 v1.0.0 升级，在服务器执行现有运行目录中的更新脚本：

```bash
sudo bash /data/codex-agent-platform/deploy.sh update
```

请将路径替换为实际运行目录。更新会构建镜像、停服备份、重启并验证，保留配置、授权和历史。备份包含敏感数据，请预留磁盘空间并私密保管；健康验证失败不会自动降级数据库，恢复步骤见 [部署文档](https://github.com/NM1024/codex-agent-platform/blob/v1.0.1/docs/DEPLOYMENT.md)。

若旧脚本尚不支持 `update`，先使用独立更新器：

```bash
curl -fL https://github.com/NM1024/codex-agent-platform/releases/latest/download/update.sh -o /tmp/codex-platform-update.sh
sudo bash /tmp/codex-platform-update.sh update
```

升级到 v1.0.1 后，如需网页升级，在 Linux/systemd 宿主机额外安装一次可选服务：

```bash
sudo bash /data/codex-agent-platform/deploy.sh enable-web-update
```

请使用更新成功后输出的运行目录。服务要求可信、root 所有的部署源码、运行目录与配置；安装前不会自动开放网页升级。网页升级需要维护确认，会重启服务；发布校验覆盖后端、浏览器、发布包、四个 Docker 目标及真实 Compose 更新流程，不调用真实模型。生产宿主机上的 systemd 安装仍需按部署文档验证。

此前的 v1.0.0 标签与发布文件保持不变。
