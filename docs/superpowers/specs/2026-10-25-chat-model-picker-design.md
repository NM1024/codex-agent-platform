Replace the chat composer's two form selects with one text button showing the effective model name and reasoning level as `Model - Level`. Keep the reasoning level visible when a long model name is truncated. Omit the decorative lightning icon to avoid implying an unavailable fast mode. Open a single panel containing model choices and reasoning controls. Desktop uses an anchored popover; narrow screens use an accessible bottom drawer within the current visual viewport. Preserve the existing green theme, composer drafts, attachments, send controls, save ordering and failure/retry behavior. Global settings forms retain their existing controls.

The reasoning slider has one position per supported catalog effort, with localized labels, a prominent current level, clickable labels, a reset action and accessible keyboard controls. Preview while dragging and commit once on release/keyboard completion, rather than writing intermediate steps. Model selection clears the prior reasoning override as it does today. Preserve the distinction between omitted effort (inherit configuration) and explicit null (model default). Opening a control never writes or normalizes saved configuration. Unknown saved models/efforts and unavailable catalogs remain readable without silently substituting a value. Search long catalogs.

Keep automatic per-conversation saves and explicit local error/retry feedback. New conversation choices apply on first send. Preserve existing model configuration semantics and runtime behavior. Use Node.js 24 and existing React/Ant Design dependencies. Only synthetic local fixtures; no account credentials or real model requests.
