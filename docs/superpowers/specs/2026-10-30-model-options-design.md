# 可管理的模型输出与上下文参数

用户已授权四项参数，并要求管理 Agent 和执行 Agent 都可使用，尤其管理 Agent 能合理查询、修改和核对配置。沿用现有四层模型配置：管理全局、当前管理对话、业务全局、业务插件；不改变普通速度默认值或消息内状态显示。

## 参数与默认值

| 平台字段 | 值 | 默认及说明 |
| --- | --- | --- |
| `verbosity` | `low/medium/high` | `medium`：适中；控制回复详细倾向，非硬长度限制，实际服从模型能力 |
| `reasoningSummary` | `auto/concise/detailed/none` | 管理端沿用 `concise`；执行端沿用 Codex 的 `auto`；只影响公开摘要，不改变思考强度 |
| `autoCompactTokenLimit` | null 或整数 1024–2147483647 | null：跟随模型自动压缩阈值；手动阈值不会扩展真实上下文上限 |
| `toolOutputTokenLimit` | null 或整数 256–2147483647 | null：跟随模型工具输出预算；过小可能截断重要信息 |

覆盖省略字段继承对应全局；显式 null 预算表示自动，可覆盖全局手动预算。旧配置和旧管理消息补合理角色默认值，不覆盖已保存参数。

## 调用与持久化

共享参数 schema 带枚举、边界、默认值语义和生效说明。配置、插件快照、管理消息执行快照及业务执行段记录均保留四项参数。管理设置用于下一轮；业务全局用于下一启动／恢复段；当前执行保持快照。

`verbosity`、预算分别映射固定的 Codex config 键 `model_verbosity`、`model_auto_compact_token_limit`、`tool_output_token_limit`；摘要映射 config 和每次 turn/start 的 summary。只传允许的固定键，不增加任意 Codex 配置或工具权限。

固定 Codex 0.159.2 的隔离实验已确认：config 覆盖应在新进程的 start/resume 应用；同一已加载线程的重复 resume 不保证刷新。平台本来每轮使用新 client/process，保持此机制。预算自动值需省略对应 native config 键，直接传 JSON null 会产生 i64 配置错误；前端及持久化仍用 null 表达自动。

## 界面

全局和插件模型配置增加可折叠“高级模型参数”；管理对话在模型面板内提供相同折叠区，默认收起，保持现有一行模型列表与思考区域快速开关。全局选合理默认，覆盖可继承；预算可选继承／自动／手动，手动显示带边界的 Token 数字输入。切换模型只重置模型相关的思考覆盖，保留独立速度与四项参数。中英文、手机和短键盘视口一起验证。

## 管理 Agent

通过现有 configuration_list/get/update 管理两种全局配置，plugin_execution_update 管理插件覆盖，schema 和提示词明确四项参数及取舍。管理端本地 configuration_update 应尊重可选 revision，不能丢弃调用者提交的版本。

补一个只作用于当前管理对话的 `conversation_execution` 工具。无 execution 时读取当前覆盖、有效值及内容 revision；带完整 execution 和 revision 时更新后续轮次，省略的覆盖恢复继承。当前对话身份来自 MCP bearer 的服务端上下文，模型不能指定其他对话 ID；无可信上下文拒绝。内容 revision 由当前覆盖内容计算，同步校验后写入，避免覆盖并发设置。当前正在执行的消息不会被改写，工具回包明确下一轮生效。

管理 Agent 根据目标选择必要改动，不随意切全局模型、压小预算、隐藏摘要或提高速度；具体对话需求优先当前对话，插件需求优先插件，只有明确平台级目标才改全局。读取 schema、当前值和模型目录，提交最小配置变更，再读取核对；不声称保存就证明真实模型效果或额度资格。

## 验证与范围

先写失败测试，覆盖边界、默认、继承／自动清除、持久化和快照、两端 native 请求、旧对话恢复、当前对话工具的身份／并发／下一轮生效，以及全局／插件自主管理。固定 Codex 本地无认证接收端验证实际 verbosity/summary 和一次工具结果截断，不使用真实账号。浏览器覆盖四个配置入口、模型切换保留、高级区折叠和小屏。运行 npm test、check:release 和相关浏览器回归；一次独立最终审阅。只改本地代码，不发布或生产部署。Webhook 功能仍单独保留其设计。
