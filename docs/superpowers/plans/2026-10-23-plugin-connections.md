# Per-plugin connections implementation plan

**User-approved scope:** Every plugin owns an entry address/key and optional callback address/credential. Agent creation generates a default entry path, while humans may edit it. Humans configure these fields in a modal opened from a plugin row, with field explanations and cryptographic random buttons. Missing entry configuration blocks activation, admission, trials and scheduled execution. Agents see readiness only and must tell users to finish configuration; they cannot read or update connection credentials. Keep the testing PR unmerged and do not deploy locally.

**Architecture:** Gateway owns a separate private plugin-connection store; entry keys are hashed and callback credentials are write-only. The production application enables connection policy while the generic module framework remains independent. A browser-cookie-only Manager route forwards to a dedicated internal Gateway endpoint that is absent from Agent tool contracts. Public task creation, query and artifact routes bind each key to one plugin. Human callback settings are resolved per plugin independently of Agent-editable business JSON. Legacy global ingress authentication is removed from the production configuration/UI; existing plugins require human configuration.

**Interfaces:** `store.pluginConnections` exposes `ensure(type,suggestedPath)`, `get(type)` (human-readable, never secrets), `status(type)` (Agent-safe readiness), `update(type,patch)`, `authenticate(token)` (type or null), `forPath(path)` (type or null), `assertReady(type)`, `callbackFor(type)` (private resolver). Fields: `entryAddress` (absolute URL or /hooks/ path), `entryPath` (derived), `entryKeyConfigured`, `callbackUrl`, `callbackTokenConfigured`, `ready`, `missingFields`, `revision`. Update fields: `entryAddress`, optional `entryKey`, `callbackUrl`, optional `callbackToken`, optional revision. Blank secret fields in UI are omitted; explicit null clears. Addresses/keys must be unique where they select a plugin; updates preserve unrelated plugin state.
