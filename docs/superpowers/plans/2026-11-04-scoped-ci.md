# Scoped CI implementation plan

> **For agentic workers:** Execute inline using superpowers:executing-plans.

**Goal:** Apply the user's approved scope-based checks and short failure-artifact retention without weakening release authorization.

**Architecture:** A versioned Node policy maps changed paths and reverse import consumers to browser groups. GitHub Actions consumes a fixed JSON plan and explicit release-proof job; npm caches are restored by PRs and saved only by main.

**Tech stack:** Node.js 24, GitHub Actions, Playwright, existing synthetic fixtures.

**Spec:** [CI scope and retention](../../CI.md), based on the scope/retention table approved in the conversation.

## Constraints

- Preserve the existing required `test` check name and runtime permissions.
- Use synthetic data; do not operate production or alter billing.
- Unknown changes expand verification; scoped green results cannot authorize releases.

## Review focus

- Renames/deletions, missing bases and indirect imports must not omit checks.
- Version metadata must not generate new dependency caches.
- Browser arguments must be argv values, never interpolated shell commands.
- A skipped release proof must fail publisher authorization.
- Workflow concurrency and event selection must preserve a usable exact-commit release path.
